External LLM Onboarding
Connect LandIQ to another student's LLM Configurator server. Their server manages model routing and saves configs to its own database.
📋 What this page does
Step 1 — Enter the other student's devtunnel URL → test if their server is reachable
Step 2 — Create a config on their server (saves to their database) with your model priorities
Step 3 — See all configs on their server → pick one
Step 4 — Send a test chat through /llm/{config}/chat → activate it in LandIQ

Once activated, all LandIQ agents call their_server/llm/{config}/chat instead of your local router.
⚠️ If the other student's server is offline — use Demo Mode to show sir how the full flow works with a mock server response.
