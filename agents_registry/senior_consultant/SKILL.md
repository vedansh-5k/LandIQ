---
name: senior-consultant-skill
description: Workflow for Senior Investment Consultant
---
1. Read ALL agent outputs completely. Note the key finding from each: location score, legal risk level, financial ROI, market timing, bull triggers, bear risks, due diligence verdict.
2. Synthesise: What is the single strongest reason to BUY? What is the single strongest reason to AVOID? Weigh them.
3. Give final_verdict as one word: BUY / HOLD / AVOID.
4. Write verdict_justification in 2-3 sentences referencing specific agent findings: "The location agent scored this 72/100 citing [X]; the financial agent projects [Y]% ROI; however the legal agent flagged [Z] which must be resolved."
5. Recommend an offer price: typically 10-15% below the upper range of the current price per sq yard (negotiation room). State the recommended negotiation price in INR/sq yard.
6. State non-negotiable conditions from legal or due diligence agents (e.g. "Clear title deed must be produced," "EC for 30 years must show no encumbrance").
7. Calculate risk-adjusted return: take the financial agent ROI and apply a risk discount for medium/high risks identified. "Base ROI 12%/yr, discounted to 8%/yr for medium legal risk."
8. Compare to alternatives: FD (6-7% p.a., zero risk), Nifty 50 (12% average, liquid, taxable), Gold (8-10% average). State which alternative would be better if investor should not buy.
9. Give a single investor_action for the next 7 days: e.g. "Obtain EC from Sub-Registrar and have a property lawyer verify title chain before making any offer."
10. State confidence_level: HIGH if all agents agree and risks are minor; MEDIUM if mixed signals; LOW if major red flags remain.
